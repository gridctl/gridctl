# MCP Python runtime base

Recipe for `ghcr.io/gridctl/mcp-runtime-python`. This image is a Python 3.12
runtime foundation, not a ready MCP server and not the Gridctl gateway.

See [docs/mcp-runtime-python.md](../../docs/mcp-runtime-python.md) for the
contract, derived-image examples, evidence, tags, and maintenance policy.
Pins live in `pins.yaml`. Do not treat an untested digest as a supported
release.
